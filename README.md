# RAG-krish

Serial notes for understanding two notebooks from Krish Naik's RAG tutorial repository:

- `document.ipynb`
- `pdf_loader.ipynb`

Source notebooks:

- https://github.com/krishnaik06/RAG-Tutorials/blob/main/notebook/document.ipynb
- https://github.com/krishnaik06/RAG-Tutorials/blob/main/notebook/pdf_loader.ipynb

The notes explain the basic RAG pipeline:

```text
Raw files/PDFs
 -> LangChain Document objects
 -> text chunks
 -> embeddings
 -> vector database
 -> semantic retrieval
 -> LLM answer generation
```

Advanced RAG features are intentionally skipped.
